# Доработки

Опишите задачу и приложите адрес страницы или файл, на котором воспроизводится проблема. Для изменения правил оценки покажите ожидаемый результат и источник: документацию поисковой или AI-системы, спецификацию, пример.

Перед pull request запустите `npm test`. Не добавляйте в примеры клиентские данные, токены и закрытые адреса. Сохраните уведомление об авторстве и лицензию MIT.

# Contributing

Describe the problem and include a URL or file that reproduces it. For scoring rule changes, provide the expected result and a source (search or AI system documentation, a specification, an example). Run `npm test` before opening a pull request. Keep the copyright notice and the MIT license.
